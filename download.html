Install kaise karein

  1. Upar ka button dabao. Chrome puchhe "Ye file nuksan kar sakti hai, rakhein?", to Keep ya Download anyway dabao.
  2. Download hone ke baad file kholo. "Install unknown apps" aaye to Settings dabao aur ijazat (Allow) do. Phir wapas aake file dobara kholo.
  3. Google Play Protect warning dikhaye to More details, phir Install anyway dabao.
  4. Install hone ke baad Open dabao aur login ya naya account banao.

Ye app abhi Play Store par nahi hai, isliye ye warning aati hai. App seedha hamari website se chalta hai.
